# 需求：新增调试Tab页

## 这个Tab页主要作用:
1. 用来检查当前页面是否有书签，以及每种书签、按钮(购买按钮、购买确认按钮、神秘书签、圣约书签、刷新按钮、刷新确认按钮)的匹配值是多少。
2. 对以保存的图像素材进行回归测试，确保通过所有图像素材的校验

> 图像素材: 一系列游戏界面的截图，每个截图根据其匹配的书签或按钮进行命名，如圣约书签素材命名为: covenant_1.png、covenant_2.png；图像素材都保存到同一个目录中

**每种素材命名前缀如下:**
* 购买按钮: buyButton
* 购买确认按钮: buyConfirm
* 神秘书签: mystic
* 圣约书签：covenant
* 刷新按钮: refresh
* 刷新确认按钮: refreshYes

页面上显示每种书签、按钮名称及其匹配值，并且每个书签、按钮有一个单选框

**页面上以下按钮:**
* [检测]按钮: 点击后检测当前游戏页面，计算每种书签、按钮的匹配值；勾选匹配值最高(有书签时优先选书签)的一项的单选框(可以人为修改)
* [保存截图]按钮：保存当前游戏页面的截图，按勾选的单选框对截图文件进行命名
* [回归测试]按钮: 对所有图像素材进行回归测试，检测素材匹配值是否达到。检测完成后汇总显示回归测试结果
